API

FerriteIGA types and functions. After reinit!, assembly follows the Ferrite manual.

FerriteIGA.generate_nurbs_patch — Function
generate_nurbs_patch(name, nels, order; kwargs...)

Build a NURBS patch. name is the geometry (:plate_with_hole, :rectangle, :ring, ...). nels is how many elements in each direction. order is the degree. The Meshes page lists every name and keyword.

source
FerriteIGA.BezierGrid — Type
BezierGrid(mesh::NURBSMesh)
BezierGrid(grid::Grid)

Ferrite grid with NURBS weights and an extraction operator on each cell. BezierGrid(mesh) builds this from a NURBS patch. BezierGrid(grid) wraps an ordinary Ferrite grid.

source
FerriteIGA.BezierCoords — Type
BezierCoords

Data for one cell, from getcoordinates. x, w are the NURBS points and weights. xb, wb are the Bézier points and weights. beo is the extraction operator.

source
FerriteIGA.BezierCell — Type
BezierCell{shape, order}(nodes)

One cell of a BezierGrid. nodes are control-point numbers. order is the degree.

source
FerriteIGA.IGAInterpolation — Type
IGAInterpolation{shape, order}()

Bernstein basis of degree order on shape (RefLine, RefQuadrilateral, or RefHexahedron). Use with BezierCellValues. For a 2D vector unknown write ip^2.

source
FerriteIGA.BezierCellValues — Type
BezierCellValues(qr, ip)

Shape values on an IGA cell. Call reinit!(cv, coords) first. Then shape_value and shape_gradient return NURBS values.

source
FerriteIGA.BezierFacetValues — Type
BezierFacetValues(fqr, ip)

Shape values on an IGA face. Call reinit!(fv, coords, faceid) first.

source
FerriteIGA.VTKIGAFile — Type
VTKIGAFile(filename, grid::BezierGrid)

Write a BezierGrid to a .vtu file.
