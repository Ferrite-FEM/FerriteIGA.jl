BezierCellValues

BezierCellValues and BezierFacetValues are the isogeometric counterparts of Ferrite's CellValues and FacetValues. After a call to reinit! they behave exactly like their Ferrite counterparts, so all of Ferrite's functions for CellValues and FacetValues (getnquadpoints, getdetJdV, shape_value, shape_gradient, shape_hessian, function_value, function_gradient, spatial_coordinate, getnormal, ...) can be used, see the Ferrite FEValues reference. For details about how the values are computed, see the BezierCellValues topic guide.

Interpolation

FerriteIGA.IGAInterpolation — Type
IGAInterpolation{refshape, order}()

The interpolation used for isogeometric analysis with FerriteIGA. On the reference cell it is the tensor-product Bernstein basis of degree order on refshape (RefLine, RefQuadrilateral or RefHexahedron). Combined with the Bézier extraction operators stored in a BezierGrid, it represents the B-spline or NURBS basis of the patch.

IGAInterpolation is used wherever a Ferrite interpolation (e.g. Lagrange) is used in a standard Ferrite program: when adding fields to a DofHandler, and when constructing BezierCellValues and BezierFacetValues. Use ip^dim to obtain a vector-valued interpolation.

The order must match the order of the cells of the grid, and is currently the same in all parametric directions.

Examples

ip = IGAInterpolation{RefQuadrilateral, 2}()  # scalar, quadratic
ip_u = ip^2                                   # vector-valued, quadratic
dh = DofHandler(grid)
add!(dh, :u, ip_u)
close!(dh)

See the BezierCellValues topic guide for more details.

Cell and facet values

FerriteIGA.BezierCellValues — Type
BezierCellValues([::Type{T},] quad_rule::QuadratureRule, func_interpol::Interpolation, [geom_interpol::Interpolation]; kwargs...)

A BezierCellValues object facilitates the process of evaluating values of shape functions, gradients of shape functions, values of nodal functions, gradients and divergences of nodal functions etc. in the quadrature points of an isogeometric cell. It is the isogeometric counterpart of Ferrite's CellValues, and is used in exactly the same way.

The reference values are those of the Bernstein basis of the IGAInterpolation. When the object is reinitialized for a cell with reinit!, the Bézier extraction operator and the NURBS weights of the cell are applied, such that after the call all functions (shape_value, shape_gradient, shape_hessian, function_value, getdetJdV, ...) return values of the B-spline or NURBS basis of the patch, mapped to the physical cell.

Constructing a Ferrite CellValues with an IGAInterpolation also returns a BezierCellValues.

Arguments:

  • T: an optional argument (default to Float64) to determine the type the internal data is stored as.
  • quad_rule: an instance of a QuadratureRule.
  • func_interpol: an IGAInterpolation, or a vectorized one (e.g. ip^2), used to interpolate the approximated function.
  • geom_interpol: an optional IGAInterpolation used to interpolate the geometry. Defaults to the scalar base of func_interpol.

Keyword arguments: The following keyword arguments are experimental and may change in future minor releases

  • update_gradients: Specifies if the gradients of the shape functions should be updated (default true)
  • update_hessians: Specifies if the hessians of the shape functions should be updated (default false)
  • update_detJdV: Specifies if the volume associated with each quadrature point should be updated (default true)

Examples

ip = IGAInterpolation{RefQuadrilateral, 2}()
qr = QuadratureRule{RefQuadrilateral}(3)
cv = BezierCellValues(qr, ip)

reinit!(cv, getcoordinates(grid, cellid))
dΩ = getdetJdV(cv, 1)
∇N = shape_gradient(cv, 1, 1)

See the BezierCellValues topic guide for more details.

FerriteIGA.BezierFacetValues — Type
BezierFacetValues([::Type{T},] quad_rule::FacetQuadratureRule, func_interpol::Interpolation, [geom_interpol::Interpolation]; kwargs...)

A BezierFacetValues object facilitates the process of evaluating values of shape functions, gradients of shape functions, values of nodal functions, gradients and divergences of nodal functions etc. on the facets of an isogeometric cell. It is the isogeometric counterpart of Ferrite's FacetValues, and is used in exactly the same way.

It is reinitialized for facet facetnr of a cell with reinit!(fv, getcoordinates(grid, cellid), facetnr), see reinit!. After that, the values are those of the B-spline or NURBS basis, and getnormal returns the outward unit normal of the (curved) facet.

Constructing a Ferrite FacetValues with an IGAInterpolation also returns a BezierFacetValues.

Arguments:

  • T: an optional argument (default to Float64) to determine the type the internal data is stored as.
  • quad_rule: an instance of a FacetQuadratureRule.
  • func_interpol: an IGAInterpolation, or a vectorized one (e.g. ip^2), used to interpolate the approximated function.
  • geom_interpol: an optional IGAInterpolation used to interpolate the geometry. Defaults to the scalar base of func_interpol.

Keyword arguments: The following keyword arguments are experimental and may change in future minor releases

  • update_gradients: Specifies if the gradients of the shape functions should be updated (default true)
  • update_hessians: Specifies if the hessians of the shape functions should be updated (default false)

Examples

ip = IGAInterpolation{RefQuadrilateral, 2}()
fqr = FacetQuadratureRule{RefQuadrilateral}(3)
fv = BezierFacetValues(fqr, ip)

for (cellid, facetnr) in getfacetset(grid, "left")
    reinit!(fv, getcoordinates(grid, cellid), facetnr)
    # ...
end

Reinitialization

The values are updated for a cell with Ferrite's reinit! function, which has the following methods for BezierCellValues and BezierFacetValues:

reinit!(cv::BezierCellValues, bc::BezierCoords)
reinit!(cv::BezierCellValues, (xb, wb))
reinit!(fv::BezierFacetValues, bc::BezierCoords, facetnr::Int)
reinit!(fv::BezierFacetValues, (xb, wb), facetnr::Int)

The first form, with a BezierCoords obtained from getcoordinates(grid, cellid), is the recommended one. The second form takes the Bézier control points xb and Bézier weights wb directly, and requires that the extraction operator and NURBS weights of the cell have been set beforehand with set_bezier_operator!.

FerriteIGA.set_bezier_operator! — Function
set_bezier_operator!(cv::Union{BezierCellValues, BezierFacetValues}, beo::BezierExtractionOperator)
set_bezier_operator!(cv::Union{BezierCellValues, BezierFacetValues}, beo::BezierExtractionOperator, w::Vector)

Set the Bézier extraction operator beo of the current cell, and optionally the NURBS weights w of the cell, in cv. They are used by the next call to reinit!(cv, (xb, wb)) to transform the Bernstein basis into the NURBS basis.

This is only needed when calling reinit! with the Bézier control points and weights directly. The recommended reinit!(cv, getcoordinates(grid, cellid)) takes the operator and weights from the BezierCoords and calls set_bezier_operator! internally.

Examples

xb, wb, x, w = get_bezier_coordinates(grid, cellid)
set_bezier_operator!(cv, get_extraction_operator(grid, cellid), w)
reinit!(cv, (xb, wb))
