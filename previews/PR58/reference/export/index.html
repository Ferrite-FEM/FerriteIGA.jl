Export

FerriteIGA writes VTK files in which every cell is an exact rational Bézier cell, so that the curved geometry and the spline solution are visualized without additional subdivision. See the Export topic guide for more details.

FerriteIGA.VTKIGAFile — Type
VTKIGAFile(filename::String, grid::BezierGrid; kwargs...)
VTKIGAFile(f::Function, filename::String, grid::BezierGrid; kwargs...)

Create a VTK file (.vtu) for visualizing a BezierGrid and data on it, e.g. in ParaView. It is the isogeometric counterpart of Ferrite's VTKGridFile, and is used in the same way.

Every cell is written as a VTK Bézier cell (VTK_BEZIER_CURVE, VTK_BEZIER_QUADRILATERAL or VTK_BEZIER_HEXAHEDRON), defined by the Bézier control points and weights of the cell, so the exact (curved) geometry is represented. Since the Bézier control points are local to each cell, the VTK grid is discontinuous: every cell has its own copy of its points.

Data is added with write_solution, write_projection, write_node_data and write_cell_data, as for a VTKGridFile. Solution fields and projections are evaluated in each cell at the reference coordinates of the Bernstein basis (the equidistant points of the IGAInterpolation), and these values are attached to the points of the cell. Keyword arguments are passed on to WriteVTK.vtk_grid.

The file is written to disk when it is closed, either explicitly with close(vtk) or at the end of the do-block.

Examples

VTKIGAFile("solution.vtu", grid) do vtk
    write_solution(vtk, dh, u)
end

See the Export topic guide for more details.

source

The following Ferrite functions can be used with a VTKIGAFile:

  • write_solution(vtk::VTKIGAFile, dh, u)
  • write_projection(vtk::VTKIGAFile, proj::L2Projector, vals, name)
  • write_node_data(vtk::VTKIGAFile, nodedata, name)
  • write_cell_data(vtk::VTKIGAFile, celldata, name)

See the Ferrite export reference for the documentation of these functions.
