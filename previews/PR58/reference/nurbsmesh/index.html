NURBSMesh

A NURBSMesh is a single tensor-product B-spline or NURBS patch. For more details about the data structure and how to refine it, see the NURBSMesh topic guide, and for the underlying spline theory the Splines topic guide.

Main type

FerriteIGA.NURBSMesh — Type
NURBSMesh(knot_vectors::NTuple{pdim, Vector{T}}, orders::NTuple{pdim, Int}, control_points::Vector{Vec{sdim, T}}, [weights::Vector{T}])

A single tensor-product B-spline or NURBS patch with parametric dimension pdim and spatial dimension sdim.

Arguments:

  • knot_vectors: one (non-decreasing) knot vector per parametric direction.
  • orders: the polynomial degree in each parametric direction.
  • control_points: the control points. They are ordered with the first parametric direction running fastest, i.e. control point $(i, j)$ of a 2D patch with $n_1$ basis functions in the first direction has index $i + (j - 1) n_1$.
  • weights: the NURBS weight of each control point. Defaults to all ones, which gives a B-spline patch.

The number of control points must be $\prod_d (\mathrm{length}(\Xi_d) - p_d - 1)$. The cells (elements) of the patch are the non-empty knot spans; knot spans of zero length (from repeated knots) are skipped.

A NURBSMesh describes the geometry and the spline space. For analysis, it is converted to a BezierGrid. Simple patches can be created with generate_nurbs_patch, and refined with knotinsertion, orderelevation and smoothnesselevation.

Examples

A quarter of a circle with radius 1 as a quadratic NURBS curve:

knot_vectors = ([0.0, 0.0, 0.0, 1.0, 1.0, 1.0],)
control_points = [Vec((1.0, 0.0)), Vec((1.0, 1.0)), Vec((0.0, 1.0))]
weights = [1.0, 1 / sqrt(2), 1.0]
mesh = NURBSMesh(knot_vectors, (2,), control_points, weights)

See the NURBSMesh topic guide for more details.

Evaluation

FerriteIGA.eval_parametric_coordinate — Function
eval_parametric_coordinate(mesh::NURBSMesh{pdim}, ξ::Vec{pdim})

Evaluate the B-spline geometry map of the patch at the parametric coordinate ξ, i.e. return the physical point $\boldsymbol{x}(\boldsymbol{\xi}) = \sum_A N_A(\boldsymbol{\xi}) \boldsymbol{X}_A$.

Warning

The NURBS weights are currently not taken into account, so the result is only exact for B-spline patches (all weights equal to one). Furthermore, all basis functions are evaluated, so the function is slow for large patches.

source
FerriteIGA.parent_to_parametric_map — Function
parent_to_parametric_map(mesh::NURBSMesh{pdim}, cellid::Int, xi::Vec{pdim})

Map the coordinate xi in the parent (reference) domain $[-1, 1]^{pdim}$ of cell cellid to the corresponding coordinate in the parametric (knot) domain of the patch. The result is returned as a Vector with pdim entries.

Together with eval_parametric_coordinate this can be used to find the physical position of a point on a cell.

Refinement

The refinement functions come in two variants. The non-mutating functions take a NURBSMesh and return a new, refined mesh. The mutating functions (ending with !) work directly on the arrays that define a patch, which is useful when several refinement steps are applied before the mesh is (re)built.

FerriteIGA.knotinsertion — Function
knotinsertion(mesh::NURBSMesh, ξ; dir::Int)

h-refinement: return a new NURBSMesh with the knot value ξ inserted once in parametric direction dir. The geometry and the parametrization are unchanged, but the spline space is enriched. Inserting a new value splits a knot span into two cells, with continuity $C^{p-1}$ across the new knot. Inserting an existing value instead increases its multiplicity $m$ and lowers the continuity there to $C^{p-m}$.

The input mesh is not modified, see knotinsertion! for the in-place version.

Examples

mesh = generate_nurbs_patch(:rectangle, (1, 1), 2; size = (1.0, 1.0))
mesh = knotinsertion(mesh, 0.0; dir = 1)  # two cells in the first direction
source
FerriteIGA.orderelevation — Function
orderelevation(mesh::NURBSMesh; dir::Int)

p-refinement: return a new NURBSMesh with the polynomial degree raised by one in parametric direction dir. The geometry and parametrization are unchanged. The multiplicity of every knot is increased by one, so the continuity across existing knots is preserved.

Note that BezierGrid currently requires the same degree in all directions, so elevate the degree in every direction before creating the grid.

The input mesh is not modified, see orderelevation! for the in-place version.

source
FerriteIGA.smoothnesselevation — Function
smoothnesselevation(mesh::NURBSMesh, new_knots::AbstractVector; dir::Int)

k-refinement: return a new NURBSMesh where the degree is first raised by one in parametric direction dir, and then each value in new_knots is inserted once. Since the knots are inserted after the degree elevation, the continuity across the new knots is $C^{p}$, where $p$ is the original degree. This gives a smoother spline space than doing the two operations in the opposite order.

The input mesh is not modified, see smoothnesselevation! for the in-place version.

source
FerriteIGA.knotinsertion! — Function
knotinsertion!(knot_vectors, orders, control_points, weights, ξ; dir::Int)

h-refinement: insert the knot value ξ once in parametric direction dir, using Boehm's algorithm [5]. The knot vector knot_vectors[dir], the control_points and the weights are updated in-place such that the geometry is unchanged. Returns nothing.

The arrays are those that define a NURBSMesh (and are e.g. obtained by copying the fields of an existing mesh). After refinement, create a new NURBSMesh from the arrays so that the element connectivity is updated.

See knotinsertion for a version that operates on a NURBSMesh.

Examples

kv = (copy(mesh.knot_vectors[1]), copy(mesh.knot_vectors[2]))
cp = copy(mesh.control_points)
w = copy(mesh.weights)
for ξ in (-0.5, 0.0, 0.5)
    knotinsertion!(kv, mesh.orders, cp, w, ξ; dir = 1)
end
mesh = NURBSMesh(kv, mesh.orders, cp, w)
source
FerriteIGA.orderelevation! — Function
orderelevation!(knot_vectors, orders, control_points, weights; dir::Int) -> orders

p-refinement: raise the polynomial degree by one in parametric direction dir, using algorithm A5.9 of [5]. The knot vector knot_vectors[dir], the control_points and the weights are updated in-place such that the geometry is unchanged. Since orders is a tuple, the new orders are returned.

After refinement, create a new NURBSMesh from the arrays. See orderelevation for a version that operates on a NURBSMesh.

source
FerriteIGA.smoothnesselevation! — Function
smoothnesselevation!(knot_vectors, orders, control_points, weights, new_knots; dir::Int) -> orders

k-refinement: raise the degree by one in parametric direction dir with orderelevation!, then insert each value of new_knots with knotinsertion!. The new knots have continuity $C^{p}$, where $p$ is the original degree. The arrays are updated in-place, and the new orders are returned.

After refinement, create a new NURBSMesh from the arrays. See smoothnesselevation for a version that operates on a NURBSMesh.
