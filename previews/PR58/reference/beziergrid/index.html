BezierGrid

A BezierGrid is a Ferrite grid (Ferrite.AbstractGrid) in which the nodes are the control points of a spline patch, and every cell additionally stores its Bézier extraction operator. For more details see the BezierGrid topic guide.

Grid and cells

FerriteIGA.BezierGrid — Type
BezierGrid(mesh::NURBSMesh)
BezierGrid(grid::Grid)
BezierGrid(cells, nodes, weights, extraction_operators; cellsets, nodesets, facetsets, vertexsets)

A Ferrite grid (<: Ferrite.AbstractGrid) for isogeometric analysis. A BezierGrid is a standard Ferrite.Grid in which

  • the nodes are the control points of the spline patch,
  • the cells are BezierCells, one for each non-empty knot span,

and which additionally stores the NURBS weight of every control point and the BezierExtractionOperator of every cell. Since it is a Ferrite grid, it can be used with DofHandler, ConstraintHandler, addfacetset!, getfacetset, etc. exactly as in a standard Ferrite program.

getcoordinates(grid::BezierGrid, cellid) returns a BezierCoords instead of a vector of node coordinates.

Constructors

  • BezierGrid(mesh::NURBSMesh): create the grid from a NURBS patch, see generate_nurbs_patch. This computes the Bézier extraction operators from the knot vectors. The orders of the patch must be equal in all parametric directions.
  • BezierGrid(grid::Grid): wrap a standard Ferrite grid, with unit weights and without extraction operators. This can be used to mix isogeometric and standard cells.
  • BezierGrid(cells, nodes, weights, extraction_operators; kwargs...): create the grid from its parts. extraction_operators contains one (possibly nothing) extraction operator per cell. The keyword arguments are the sets, as for Ferrite.Grid.
Boundary sets

generate_nurbs_patch does not define any facet or node sets. Add them with addfacetset! and addnodeset!, which select facets based on the control points. For the geometries generated by FerriteIGA the boundary control points lie exactly on the (straight) boundaries, but in general control points need not lie on the geometry.

Examples

mesh = generate_nurbs_patch(:plate_with_hole, (4, 4), 2)
grid = BezierGrid(mesh)
addfacetset!(grid, "left", x -> x[1] ≈ -4.0)

See the BezierGrid topic guide for more details.

FerriteIGA.BezierCell — Type
BezierCell{refshape, order}(nodes::NTuple{N, Int})

A cell of a BezierGrid, i.e. one non-empty knot span of a spline patch, with reference shape refshape (RefLine, RefQuadrilateral or RefHexahedron) and polynomial degree order. The nodes are the indices of the N = (order + 1)^dim control points whose basis functions are non-zero on the cell, ordered according to the Bernstein basis of IGAInterpolation.

Unlike a Lagrange cell, neighboring BezierCells share several layers of nodes, reflecting the higher continuity of the spline basis.

BezierCell can be passed to Ferrite's generate_grid to create a uniform B-spline grid of a line, rectangle or box directly:

grid = generate_grid(BezierCell{RefQuadrilateral, 2}, (10, 10), Vec((0.0, 0.0)), Vec((1.0, 1.0)))

FerriteIGA.BezierExtractionOperator — Type
BezierExtractionOperator{T}

The Bézier extraction operator $\mathbf{C}^e$ of one cell. It expresses the B-spline basis functions that are non-zero on the cell as linear combinations of the Bernstein polynomials of the same degree,

\[\mathbf{N}^e(\boldsymbol{\xi}) = \mathbf{C}^e \mathbf{B}(\boldsymbol{\xi}).\]

The operator is stored row-wise (one sparse vector per B-spline basis function on the cell) in the field C. It is computed from the knot vectors when a BezierGrid is created from a NURBSMesh, and is obtained for a cell with get_extraction_operator or as the beo field of a BezierCoords.

See the BezierGrid topic guide for more details.

Cell coordinates

The function getcoordinates(grid::BezierGrid, cellid) returns a BezierCoords, which holds everything that is needed to reinit! a BezierCellValues. The functions below give access to the individual parts.

FerriteIGA.BezierCoords — Type
BezierCoords{sdim, T}

The geometric data of one cell of a BezierGrid, returned by getcoordinates(grid::BezierGrid, cellid). In a standard Ferrite program getcoordinates returns a vector of node coordinates; for an isogeometric cell more information is needed to reinit! a BezierCellValues, and BezierCoords bundles all of it:

  • x::Vector{Vec{sdim,T}}: the NURBS control points of the cell,
  • w::Vector{T}: the NURBS weights of the cell,
  • xb::Vector{Vec{sdim,T}}: the Bézier control points of the cell,
  • wb::Vector{T}: the Bézier weights of the cell,
  • beo: the BezierExtractionOperator of the cell (or nothing for cells without one).

A BezierCoords can be passed directly to reinit!:

coords = getcoordinates(grid, cellid)
reinit!(cellvalues, coords)

A pre-allocated BezierCoords can be updated in-place with getcoordinates!(coords, grid, cellid).

FerriteIGA.get_nurbs_coordinates — Function
get_nurbs_coordinates(grid::BezierGrid, cellid::Int)

Return the NURBS control points of cell cellid, i.e. the coordinates of the nodes of the cell. Note that, in contrast to a Lagrange grid, control points do in general not lie on the geometry. For the Bézier control points of the cell, see get_bezier_coordinates.

source
FerriteIGA.get_nurbs_weights — Function
get_nurbs_weights(grid::BezierGrid, cellid::Int)

Return a vector with the NURBS weights of the control points of cell cellid, in the same order as the nodes of the cell. For a B-spline patch all weights are equal to one.

See also get_nurbs_weights! for an in-place version.

source
FerriteIGA.get_nurbs_weights! — Function
get_nurbs_weights!(w::Vector, grid::BezierGrid, cellid::Int)
get_nurbs_weights!(w::Vector, grid::BezierGrid, cell::AbstractCell)

Fill w with the NURBS weights of the control points of the cell, given either as its index cellid or as the cell itself. w must have (at least) one entry per node of the cell.

See also get_nurbs_weights and get_bezier_coordinates!.

FerriteIGA.get_bezier_coordinates — Function
get_bezier_coordinates(grid::BezierGrid, cellid::Int) -> (xb, wb, x, w)

Return the Bézier control points xb, the Bézier weights wb, the NURBS control points x and the NURBS weights w of cell cellid.

See get_bezier_coordinates! for the definitions and an in-place version.

source
FerriteIGA.get_bezier_coordinates! — Function
get_bezier_coordinates!(xb, wb, x, w, grid::BezierGrid, cellid::Int)

Compute, in-place, the NURBS control points x and weights w of cell cellid, and the corresponding Bézier control points xb and Bézier weights wb. The Bézier quantities are obtained with the extraction operator $\mathbf{C}^e$ of the cell as

\[w^b_j = \sum_i C^e_{ij} w_i, \qquad \boldsymbol{x}^b_j = \frac{1}{w^b_j} \sum_i C^e_{ij} w_i \boldsymbol{x}_i.\]

If the cell has no extraction operator (e.g. a standard Ferrite cell), xb and wb are copies of x and w. All vectors must have one entry per node of the cell.

Usually it is more convenient to call getcoordinates(grid, cellid), which returns all of this data as a BezierCoords.

source
FerriteIGA.get_extraction_operator — Function
get_extraction_operator(grid::BezierGrid, cellid::Int)

Return the BezierExtractionOperator $\mathbf{C}^e$ of cell cellid, or nothing if the cell does not have one (e.g. a standard Ferrite cell in a mixed grid).

Iteration caches

FerriteIGA.IGACellCache — Type
IGACellCache(dh::DofHandler, flags::UpdateFlags = UpdateFlags())

The isogeometric counterpart of Ferrite's CellCache, for a DofHandler defined on a BezierGrid. It holds pre-allocated storage for the data of one cell, and is updated for cell cellid with reinit!(cache, cellid). After that, the following functions can be used:

  • getcoordinates(cache): the BezierCoords of the cell,
  • celldofs(cache): the global degrees of freedom of the cell,
  • getnodes(cache): the node (control point) indices of the cell,
  • cellid(cache): the index of the cell.

flags determines which of the data is updated, see Ferrite's UpdateFlags.

Examples

cc = IGACellCache(dh)
for cellid in 1:getncells(grid)
    reinit!(cc, cellid)
    reinit!(cellvalues, getcoordinates(cc))
    assemble_element!(ke, cellvalues)
    assemble!(assembler, celldofs(cc), ke)
end

FerriteIGA.IGAFaceCache — Type
IGAFaceCache(dh::DofHandler, flags::UpdateFlags = UpdateFlags())

The isogeometric counterpart of Ferrite's FacetCache, for a DofHandler defined on a BezierGrid. It is updated with reinit!(cache, FacetIndex(cellid, facetnr)), after which getcoordinates, celldofs, getnodes and cellid return the data of the cell that the facet belongs to, see IGACellCache.
