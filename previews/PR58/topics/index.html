Topic guides

This is an overview of the topic guides. The topic guides contain in-depth explanations and discussions about isogeometric analysis concepts, and how these are realized in FerriteIGA. They are best read roughly in order: the first guide introduces the spline spaces, the next three follow the data from a spline patch to the values used in the element routines, and the last discusses visualization.
