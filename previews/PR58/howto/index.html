How-to guides

This page gives an overview of the how-to guides. How-to guides address various common tasks one might want to do in an isogeometric analysis program. Many of the guides are extensions, or build on top of, the tutorials and, therefore, some familiarity with FerriteIGA (and Ferrite) is assumed.

There are no how-to guides yet. In the meantime, the Ferrite how-to guides apply to FerriteIGA as well, since the assembly, boundary condition and solver parts of a program are the same.
