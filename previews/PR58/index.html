FerriteIGA.jl

Welcome to the documentation for FerriteIGA.jl! FerriteIGA is an extension of the Ferrite.jl finite element toolbox for isogeometric analysis (IGA). It provides spline (B-spline and NURBS) geometries and basis functions, and makes them available through the same interface as standard finite elements in Ferrite. Programs written with FerriteIGA therefore look almost exactly like Ferrite programs: degrees of freedom, boundary conditions, assembly and post-processing all work in the same way.

How the documentation is organized

This high level view of the documentation structure will help you find what you are looking for. The document is organized as follows[1]:

  • Getting started summarizes how an isogeometric program differs from a Ferrite program, and is the best place to start.
  • Tutorials are thoroughly documented examples which guide you through the process of solving partial differential equations using FerriteIGA.
  • Topic guides contain more in-depth explanations and discussions about isogeometric analysis concepts, and specifically how these are realized in FerriteIGA.
  • API reference contains the technical API reference of functions and types (e.g. the documentation strings).
  • How-to guides will guide you through the steps involved in addressing common tasks and use-cases. These usually build on top of the tutorials and thus assume basic knowledge of how FerriteIGA works.

In addition, the document contains Developer documentation, which documents the internals of FerriteIGA, and a list of Cited literature.

Since FerriteIGA builds on Ferrite, the Ferrite documentation is a useful companion. In particular, it is recommended to be familiar with the first Ferrite tutorial, Heat equation, before reading this documentation.

Isogeometric analysis

Isogeometric analysis was introduced by Hughes et al. [1] as a Galerkin method whose basis functions are taken from computer aided design (CAD): B-splines and non-uniform rational B-splines (NURBS) [2]. The idea is to use the same functions to describe the geometry and to approximate the solution, which gives the method its name. This has a number of consequences:

  • Exact geometry. A geometry designed in CAD is described exactly by the analysis model, already on the coarsest mesh. NURBS represent conic sections such as circles, cylinders and spheres exactly, so for example the circular hole in the Infinite plate with hole tutorial is exact, and the geometry is unchanged when the mesh is refined.
  • Higher continuity. The smoothness of a spline basis is set by its knot vector. A spline of degree $p$ is, in general, $C^{p-1}$-continuous between elements, whereas standard finite elements are only $C^0$. Stresses and strains are therefore continuous inside a patch, and problems that need second derivatives of the unknown, such as the Kirchhoff plate, can be discretized directly with a quadratic basis.
  • Better spectral properties. For the same number of degrees of freedom, smooth spline spaces approximate the eigenvalues and eigenmodes of a problem considerably better than $C^0$ finite elements, whose higher frequencies diverge from the exact ones [3]. This is shown in the Structural vibrations tutorial.
  • Flexible refinement. A mesh can be refined by inserting knots (h-refinement), by raising the degree (p-refinement), or by a combination that raises both the degree and the continuity (k-refinement), without changing the geometry.

A spline basis function is non-zero over several neighboring elements, which does not fit directly into a finite element code that evaluates shape functions element by element. FerriteIGA uses Bézier extraction [4] to overcome this: on each element the spline basis is written as a linear combination of Bernstein polynomials, which are defined on a single reference element exactly like standard finite element shape functions. This is what allows Ferrite's machinery to be reused, and is explained in the BezierGrid and BezierCellValues topic guides.

Installation

To use FerriteIGA you first need to install Julia, see https://julialang.org/ for details. Installing FerriteIGA can then be done from the Pkg REPL; press ] at the julia> prompt to enter pkg> mode:

pkg> add FerriteIGA

This will install FerriteIGA and all necessary dependencies, including Ferrite. Press backspace to get back to the julia> prompt. Finally, to load FerriteIGA, use

using FerriteIGA

FerriteIGA re-exports Ferrite (and Tensors), so using Ferrite is not needed. You are now all set to start using FerriteIGA!
