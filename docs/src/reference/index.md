strings of all exported types and functions. FerriteIGA re-exports Ferrite, and the
functionality not listed here (e.g. `DofHandler`, `ConstraintHandler`, assembly,
`QuadratureRule`) is documented in the
[Ferrite API reference](https://ferrite-fem.github.io/Ferrite.jl/stable/reference/).
