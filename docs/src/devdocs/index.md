# Developer documentation

Here you can find documentation of the internals of FerriteIGA which is useful when
developing the library.

There is no developer documentation yet. The
[topic guides](../topics/index.md) describe how the main data structures
([`NURBSMesh`](@ref), [`BezierGrid`](@ref) and [`BezierCellValues`](@ref)) work, and the
[Ferrite developer documentation](https://ferrite-fem.github.io/Ferrite.jl/stable/devdocs/)
describes the parts of Ferrite that FerriteIGA builds on.
